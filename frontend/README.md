# Front-end React + Tailwind

Este front-end consome a API do backend para gerenciar tarefas.

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. O app será aberto em `http://localhost:5173`.

## Integração com a API

O front-end chama o backend em `http://localhost:3000/api/tarefas`.

Certifique-se de que o backend esteja rodando antes de usar o aplicativo.
